Auto Reboot

Intune Remediation · Reboots devices with uptime over 10 days
Test in a pilot group before you point this at the fleet. Detection exits 1 to trigger remediation, 0 to stay put.
Detection Script
D
Detect uptime over 10 days detection
Exits 1 (non-compliant) to trigger remediation. Exits 0 if clean.
›
# Flags devices up for 10 days or more. $days = (New-TimeSpan -Start (Get-CimInstance Win32_OperatingSystem).LastBootUpTime).Days if ($days -ge 10) { Write-Output "Non-compliant: up $days days" exit 1 } Write-Output "Compliant: up $days days" exit 0
Remediation Script
R
Warn user, reboot in 15 minutes remediation
Runs only when detection exits 1.
›
# Warns the user, then reboots in 15 minutes. shutdown.exe /r /t 900 /c 'Maintenance reboot in 15 minutes. Save your work.'
Intune Remediation Settings
Run this script using the logged on credentials No
Enforce script signature check No
Run script in 64-bit PowerShell host Yes
