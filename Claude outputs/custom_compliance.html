🔍 Custom Compliance

For the checks Intune has no setting for.
click a policy | each one is a discovery script and a JSON rules file
Every policy here is two files. Upload the script under Devices, Compliance, Scripts, then create a compliance policy of type Custom and attach the JSON. No extra licence, no third party tooling.
The script runs as System in 64 bit PowerShell and must return one compressed line of JSON. Anything written to the pipeline that is not that line breaks the evaluation and the device reports an error, not a failure.
Policies
Start with antivirus. It is the one every client asks about and the one built in compliance does worst.
🛡️AntivirusPick Vendor Confirms the tenant's antivirus product is registered with Windows Security Center and actively running. Six vendors, one toggle.
🔑BitLocker Key Escrow Coming. Encrypted is not the same as recoverable. Confirms the recovery key actually reached Entra.
🔁Reboot Age Coming. Flags devices that have not restarted in 14 days, the ones that silently stop patching.
👤Local Administrators Coming. Fails if anything outside your approved SIDs sits in the local Administrators group.
💽Free Disk Space Coming. Under 15 percent free and updates quietly stop installing.
🧯Tamper Protection Coming. Defender setting with no built in compliance equivalent, and the first thing malware turns off.
